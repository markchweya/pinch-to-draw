# Keyboard shortcuts

## Anywhere (global hotkeys)

| Keys | Action |
|---|---|
| Ctrl+Alt+D | Switch Draw / Mouse mode |
| Ctrl+Alt+A | Pinch drawing on / off |
| Ctrl+Alt+Z | Undo |
| Ctrl+Alt+C | Clear all |
| Ctrl+Alt+H | Hide / show drawings |
| Ctrl+Alt+W | Whiteboard on / off |
| Ctrl+Alt+Q | Quit |

If another program already uses one of these, the app tells you when it starts.
The rest keep working.

## In Draw mode

| Key | Action |
|---|---|
| P | Pen |
| H | Highlighter |
| L | Line |
| A | Arrow |
| R | Rectangle |
| O | Ellipse |
| T | Text |
| E | Eraser |
| 1 – 8 | Colours |
| [ and ] | Thinner / thicker |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Delete | Clear all |
| W / B | Whiteboard / blackboard |
| Esc | Back to Mouse mode |

Hold **Shift** while drawing to make straight lines, 45° angles, perfect squares
and perfect circles.

## Typing text

Click where the text should start and type. **Enter** starts a new line,
**Backspace** deletes, and **Esc** or a click somewhere else finishes the text.
